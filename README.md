# 嘉義輕軌實境

手機網頁示範。把規劃中的嘉義市輕軌（嘉義市區輕軌／高鐵聯外輕軌藍線，以及較早期的路網構想）疊到相機畫面上：靠近並朝向車站時，會看到站名與距離；附近的路線會畫在地面方向上。

不需安裝 App。以 HTTPS 在 iPhone Safari 與 Android Chrome 開啟即可。桌面或沒有相機時，改看平面地圖。人在嘉義以外，可以點一座車站模擬站在那裡。

**這是示範，不是竣工圖，也不能拿來導航。** 藍線中間站的站名與座標是依公開路廊推估的。正式測量公布後，替換 `public/data/chiayi-lrt.geojson` 即可。

## 本地執行

```bash
npm install
npm run dev
```

開發伺服器是 [http://127.0.0.1:4179](http://127.0.0.1:4179)。相機、定位與 iPhone 的方向感測都需要 HTTPS，本機的 `http://` 只能看地圖與模擬。

```bash
npm test
npm run build
npm run preview
```

`dist/` 是純靜態檔，可放到任何靜態網站空間。

GitHub Pages 專案網站位址是 `https://mmmarc2025.github.io/archiayi/`。推上 `main` 後，`.github/workflows/pages.yml` 會以 `BASE_PATH=/archiayi/` 執行 `npm run build`，再發布 `dist/`。GeoJSON 用 `import.meta.env.BASE_URL`，所以會載入 `/archiayi/data/chiayi-lrt.geojson`。本機開發不要設 `BASE_PATH`，資產仍用相對路徑。

## 在手機上

1. 用 HTTPS 網址開啟。
2. 點「開啟實境」。
3. iPhone（Safari）會先問「動作與方向存取」，接著問相機與定位。三個都要允許。若之前按過不允許：設定 → Safari → 相機、定位服務、動作與方向存取，改成詢問或允許，再重新整理。
4. Android（Chrome）在網址列的鎖頭開啟相機與位置。方向使用裝置羅盤。
5. 請直向拿手機。標籤若和街景對不齊，點「校正方向」。
6. 沒有羅盤時，用手指左右滑動來環視（往右滑，視線往左轉）。

地圖上點車站可以「在這裡模擬」或「用實境看」。也可以打開「模擬定位」清單。

## 畫面上有什麼

- **藍線**：臺鐵嘉義站北側 → 自由路 → 世賢路 → 高鐵大道 → 高鐵嘉義站。可行性研究已於 2024 年 6 月送交通部審查，尚未核定。公布長度 15.06 公里、13 站、1 座機廠；高架約 10.06 公里、平面約 5 公里。本檔沿著道路描出來約 15.3 公里。
- **藍色實線／琥珀色實線**：依公開說明把市區段與高鐵站一端標成可能高架，把埤麻腳、魚寮一帶約 4.8 公里標成可能平面。哪三站是平面，官方沒有逐站公布。
- **虛線**：2022 年路網與維基百科整理的延伸構想（北門、蘭潭、港坪、角仔寮、縣政府、朴子、故宮南院、馬稠後）。只連起迄，不代表軌道會走直線。

B01「嘉義車站」與 B13「高鐵嘉義站」的角色有公開說明。B02–B12 的名稱（保安、北湖、大溪、大溪西、竹村、埤麻腳、港尾、魚寮、新埤、新埤南、後庄）是沿路廊約略等距後，用所在里、聚落命名，**都不是官方站名**。

## 座標怎麼來的

公開文件沒有中間站的經緯度，也沒有可供套繪的大比例尺圖說。作法是：

1. 依嘉義市政府與交通部文字：自臺鐵嘉義站北側，沿自由路、世賢路、北港路、高鐵大道到高鐵嘉義站。
2. 用 OpenStreetMap 的自由路、世賢路一段、高鐵大道、高鐵東路中心線串成一條線。
3. 交通部寫到北港路。這條線在世賢路、北港路與高鐵大道的交會處轉入高鐵大道，沒有再沿北港路北繞嘉義交流道。這樣才會接近公布的 15.06 公里。若日後圖說顯示北港路占更長路段，需要重畫。
4. 三處沒有公開線形，以直線銜接，並寫在 GeoJSON 的 `metadata.blueLine.gaps`：
   - 車站北側到自由路的引道（約 0.55 公里）
   - OpenStreetMap 在嘉太大橋、埤麻腳附近中斷的高鐵大道（約 0.98 公里）
   - 高鐵大道與高鐵東路之間、進站前的南北向空檔（約 0.90 公里）
5. 13 站沿這條線約略等距。B01 放在臺鐵嘉義站北側約 110 公尺，B13 放在高鐵嘉義站站體。
6. 機廠只知道地名「埤麻腳」，圖上放在路廊經過該地的位置南側約 40 公尺。

## 實作

定位用 Geolocation，方向用 `DeviceOrientation`（iOS 會先呼叫 `DeviceOrientationEvent.requestPermission()`；有 `webkitCompassHeading` 時優先使用）。相機用後鏡頭 `getUserMedia`。左右位置依方位角；路線的上下位置有刻意拉長，否則在手機上只會貼著地平線變成一條幾乎看不見的線。平面圖是 Leaflet 與 OpenStreetMap。
